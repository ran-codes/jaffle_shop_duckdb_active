# Dagster + dbt-DuckDB Setup Guide

## Complete Steps: Add Dagster to Your dbt Project

### Step 1: Install Dagster
```bash
uv add dagster dagster-dbt dagster-webserver
```

### Step 2: Generate dbt Manifest
```bash
dbt docs generate
```

### Step 3: Create Dagster Folder
```bash
mkdir dagster_project
```

### Step 4: Create `dagster_project/__init__.py`

Create a new file called `__init__.py` inside the `dagster_project` folder and paste this code:

```python
from dagster import AssetExecutionContext, Definitions
from dagster_dbt import DbtCliResource, DbtProject, dbt_assets
from pathlib import Path

DBT_PROJECT_DIR = Path(__file__).parent.parent

dbt_project = DbtProject(
    project_dir=DBT_PROJECT_DIR,
    target="dev",
)

@dbt_assets(
    manifest=dbt_project.manifest_path,
    project=dbt_project,
)
def jaffle_shop_dbt_assets(context: AssetExecutionContext, dbt: DbtCliResource):
    yield from dbt.cli(["build"], context=context).stream()

defs = Definitions(
    assets=[jaffle_shop_dbt_assets],
    resources={"dbt": DbtCliResource(project_dir=DBT_PROJECT_DIR)},
)
```

### Step 5: Update `.gitignore`

Add these lines to your `.gitignore`:

```gitignore
# Dagster
.tmp_dagster_home*/
*.pyc
```

### Step 6: Launch Dagster
```bash
dagster dev -m dagster_project
```

### Step 7: Open Browser
Go to: **http://localhost:3000**

Click **Assets** → **Materialize all**

## What Just Happened?

1. **Dagster read** your `manifest.json`
2. **Discovered** all your dbt models (customers, orders, etc.)
3. **Created a UI** to visualize and run them
4. When you click "Materialize", it runs `dbt build`
5. You see logs and results in real-time

## Key Concepts

- **Assets**: Your dbt models become Dagster assets (materialized data)
- **Resources**: `DbtCliResource` runs dbt commands for you
- **Manifest**: Maps your dbt DAG to Dagster lineage
- **Orchestration**: Dagster schedules and runs your dbt models

## What is Dagster? (ELI5)

**Dagster is an orchestrator** - a smart scheduler + job manager + dashboard for your data pipelines.

**dbt** = Your recipe book (SQL transformations)

**Dagster** = Your kitchen manager who:
- Decides when to cook (scheduling)
- Tells the chef what to make (orchestration)
- Checks if ingredients are ready (dependencies)
- Monitors if cooking went well (observability)
- Keeps a logbook (lineage tracking)
